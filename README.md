# Dupe Studio

Catálogo estático (HTML/CSS/JS), sin build. Se despliega tal cual en Vercel.

## Estructura
- `index.html`: estructura de la página
- `css/styles.css`: estilos
- `js/productos.js`: catálogo (un perfume por línea)
- `js/app.js`: filtros, buscador, modales, WhatsApp y recomendaciones
- `vercel.json`: configuración de despliegue

## Probar en local
    python3 -m http.server 8000
Abrir http://localhost:8000
